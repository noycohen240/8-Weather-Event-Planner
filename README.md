# 8-Weather-Event-Planner

## Description
Any Weather is a website that offers a variety of activities and matches them
to weather conditions.  
The user can check the weather for a selected day and receive activity
recommendations accordingly. If rainy weather is detected, the website displays
a notification indicating a rainy day and suggests activities suitable for
rainy conditions.

## Features
- Activity suggestions based on weather conditions
- Weather display for selected days
- User-friendly and intuitive design

## Technologies
- HTML
- CSS
- JavaScript

## How to Use
1. Open the website using the link below
2. Choose the desired action from the menu
3. On the Home page, view the weather information and recommended activities
4. On the Activities page, select a day and receive activity suggestions based
   on the weather
5. On the About Us page, read information about the creators of the project and
   general details about the website
6. On the Support & Accessibility page, leave your contact details and receive
   assistance regarding support or accessibility issues

## Future Improvements
